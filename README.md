# Framework_Duartk
Inspirado no Bootstrap, mas deixa os sistemas com a formatacao inspirada no FrontEnd do Governo Federal.
Documentacao presente que mostra modelos de como se usar para montar uma interface intuitiva rapidamente
Feito originalmente para se utilizar no AppScript (Feito inicialmente para se utilizar no Appscript)


-Padrão de cores (Com base no padrão de front dos sistemas do Governo Federal)
-Interfaces formatadas mais rapidamente: Header, Sidebar, Cards e Modais pré prontos e de fácil modificação
-Tabelas, Inputs formatados e diferentes cores de Buttons
-Modais com scrips pré prontos para ativação fácil e intuitiva com botões e scripts de acordo com a necessidade do usuário
-CheckBoxs diferentes com funcionalidades de gerenciamento de conteudo
